🪗 Painel de Contatos

Este painel publica em .

Cada site guarda à parte o endereço, o token e a planilha. Ao trocar, a página abre de novo (o que não foi publicado se perde).

Cadastra contato novo, edita ou remove os que já existem, enquadra a foto e devolve os arquivos contatos.json e cidades.json já atualizados. Nada sai do seu aparelho sem você pedir: só a busca opcional de coordenadas de cidade nova, a busca opcional da foto do Instagram (feita pelo ajudante, que roda no seu computador), a leitura opcional da planilha de respostas do formulário (só com o link que você colar; se ele ficar guardado, o painel busca as respostas ao abrir), a leitura opcional dos cadastros recebidos pela página de cadastro (só depois que você entrar no Firebase com e-mail e senha; se pedir para manter a conexão, o painel busca os cadastros ao abrir) e, se você conectar um token, a publicação no GitHub.

Conexão com o GitHub (para publicar com um clique)

Com um token, o painel envia o contatos.json, o cidades.json e as fotos direto para o repositório , sem copiar e colar. O token fica só neste navegador e só é enviado ao GitHub.

Como criar o token (uma vez só)
  1. No GitHub, clique na sua foto (canto superior direito) e em Settings.
  2. No menu da esquerda, vá em Developer settings, depois Personal access tokens e Fine-grained tokens, e clique em Generate new token.
  3. Em Token name, escreva por exemplo "Painel de Contatos". Em Expiration, escolha a validade (por exemplo 90 dias; quando vencer, é só criar outro).
  4. Em Repository access, marque Only select repositories e escolha (para um token só, marque os dois repositórios; o painel guarda o token de cada site à parte, então cole-o uma vez em cada site).
  5. Em Permissions, abra Repository permissions, ache Contents e mude para Read and write. Não precisa de mais nada.
  6. Clique em Generate token, copie o código na hora (começa com github_pat_; o GitHub só mostra uma vez) e cole acima. Depois toque em Testar conexão.

Esse token só mexe nos repositórios marcados. Se perder o código ou desconfiar de vazamento, apague o token em Settings, Developer settings, e crie outro. Abra o painel como arquivo no seu computador; não o coloque no site público.

O site carrega o contatos.json e o cidades.json da mesma pasta. Com "Abrir arquivo(s)" ou "colar" dá para trazer os dois, um de cada vez. "Carregar do GitHub" pega a versão mais nova direto do repositório, sem esperar o site atualizar.

O que você quer fazer?

Escolha "Novo contato" para cadastrar, ou um contato da lista para editar os dados ou trocar a foto dele.

Cadastros recebidos pela página de cadastro

Traz os músicos que se cadastraram sozinhos pela página de cadastro (Firebase). Você confere e cadastra um de cada vez; nada entra na lista sem o seu clique. Quem já está na lista e corrigiu o próprio cadastro aparece como atualização, com o que mudou.

Falta ligar o painel ao Firebase. Preencha projectId e apiKey na linha const FIREBASE, no começo do script deste arquivo (são os mesmos valores da página de cadastro). Enquanto isso, as respostas continuam chegando pelo formulário do Google, logo abaixo.
